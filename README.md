This website is built entirely with core front-end web technologies:

- **JavaScript** (9.3%) - For interactive elements and dynamic behavior.

## 🚀 Getting Started

Since this is a static website, you don't need any complex build tools or servers to run it locally.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/akash-sarkar-2001/akash-sarkar-2001.github.io.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd akash-sarkar-2001.github.io
   ```
3. **Open the site:**
   Simply open the `index.html` file in your preferred web browser, or use a tool like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code for live reloading.
